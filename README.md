# 🔘 100 Button Showcase

A responsive web showcase featuring **100 unique HTML buttons** styled with modern CSS and enhanced with interactive JavaScript effects.

## 🚀 Overview

This repository demonstrates a variety of UI button designs and interactive visual behaviors using pure HTML, CSS, and vanilla JavaScript. From neon glows and glassmorphism to sound/state toggles, slot machines, and cyberpunk styling, this showcase serves as an interactive catalog for creative web UI components.

## ✨ Features

- **100 Unique Buttons**: Each button features its own style, theme, animation, or JavaScript interaction.
- **Pure Web Technologies**: Built with standard HTML5, CSS3, and modern ES6+ JavaScript—no frameworks or external library dependencies required.
- **Responsive Layout**: Powered by CSS Grid and Flexbox for seamless viewing on desktop, tablet, and mobile screens.
- **Interactive Visual Effects**: Includes animations, hover states, dynamic page background modifications, clip-path shapes, copy-to-clipboard actions, modal alerts, and state toggles.

## 📁 File Structure

```text
.
├── index.html   # Main HTML document containing the grid of 100 buttons
├── style.css    # Stylesheet for custom button styling, animations, and layouts
└── script.js    # JavaScript interactions and click event handlers for each button
```

## 💻 Getting Started

To run or view the showcase locally:

1. **Clone or Download the Repository**:
   ```bash
   git clone <repository-url>
   ```

2. **Open in Browser**:
   - Open `index.html` directly in any web browser (Chrome, Firefox, Safari, Edge, etc.).
   - Alternatively, serve it using a local static web server (such as VS Code Live Server or Python's `http.server`):
     ```bash
     python -m http.server 8000
     ```
     Then open `http://localhost:8000` in your browser.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup structuring the button grid showcase.
- **CSS3**: Custom keyframe animations, CSS variables, linear/radial gradients, clip paths, backdrop filters, and responsive CSS Grid.
- **JavaScript (ES6+)**: Event listeners, state management, dynamic DOM manipulation, browser APIs (Clipboard, Web Share, etc.).
